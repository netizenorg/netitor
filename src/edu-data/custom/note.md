`nn-netitor-docs.json` is generated by the netent-standard-library repo, there's a script `npm run netitor-docs` which is used to generate this file form the docs data in that repo.

`nn-ml-netitor-docs.json` is generated the same way by the netnet-machine-learning repo (`npm run netitor-docs`, outputs `build/nn-ml-netitor-docs.json`), it documents the `nn.hands()`, `nn.face()`, `nn.pose()` and `nn.prompt()` extensions.

Don't hand-edit either JSON file. `nn-docs.js` merges them, and that's what `jsHinter.js` and `jsData.js` require.
